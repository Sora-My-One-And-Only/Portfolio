# Portfolio

ゲーム企画の作品を、企画意図や設計の詳細とあわせて閲覧できるポートフォリオサイトです。

**[ポートフォリオサイトを開く](https://sora-my-one-and-only.github.io/Portfolio/)**

サイトのテーマは「一冊のゲーム設定資料集をめくるように、作品を読む」です。表紙と目次を起点に、作品一覧から気になった作品の詳細へ進めます。現在はサイトを制作中で、一部の文章や画像に仮素材を使用しています。

## 主な機能

| 機能 | できること |
| --- | --- |
| 目次とナビゲーション | 作品一覧や連絡先など、目的の章へ直接移動できます。 |
| 作品の詳細表示 | 作品カードを選ぶと、企画意図やゲームの仕組みを掲載する詳細画面が開きます。 |
| 言語切り替え | 日本語、中国語、英語を切り替えられます。 |
| 閲覧設定 | ライトとダークの切り替えに加え、BGMと効果音をそれぞれオン・オフできます。 |

## サイトの構成

| 画面・セクション | 役割 |
| --- | --- |
| 表紙・目次 | サイトの入口。ここから各章へ進めます。 |
| 30秒ガイド | 作品を見る前に、サイトの要点と主な閲覧先を確認できます。 |
| 作品一覧 | ゲームやツールを作品カードで見比べられます。 |
| 作品詳細 | 作品の概要、企画意図、仕組みを作品ごとに掲載するページです。 |
| プレイ・体験 | ブラウザで体験できる作品やツールのリンクを掲載するセクションです。 |

サイトはGitHub Pagesで公開する静的サイトです。作品詳細は作品一覧から開く画面として用意しており、閲覧中の言語設定は詳細画面にも引き継がれます。

## 工夫したポイント

### 資料集の体裁と、目的の章に進める目次

表紙、章立て、ページをめくる音で資料集の雰囲気を出しています。目次とナビゲーションを用意し、作品一覧だけを見たい場合にも直接移動できるようにしています。

### 作品一覧と詳細画面の役割分担

一覧では作品を選ぶための情報を短くまとめ、企画意図や仕組みを深く読む場所として詳細画面を設けています。
