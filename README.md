# Sora｜ゲームプランナー志望

[ポートフォリオを見る](https://sora-my-one-and-only.github.io/Portfolio/)

日本でゲーム制作を学んでいます。アクションゲームのバトルとレベルデザインに関心があります。アイデアを遊べる形にし、操作感やステージの動線を確かめながら企画を詰めています。

## 代表作

### ARCANE CHRONICLE — ルミアの冒険譚

Unityでチーム制作中の3Dアクションゲームです。戦闘中に方向キーでコマンドを入力して魔法を詠唱します。剣で攻めて魔力を回復し、敵をブレイクさせた隙に、長いコマンドが必要な強力な魔法を狙います。

- **バトルデザイン**　短い隙にはすぐに出せる魔法を使い、強力な魔法を使うときは、先に近接攻撃で詠唱する時間を作ります。
- **レベルデザイン**　火竜戦では戦闘中に足場が崩れます。次の足場へ移り、火竜との距離や攻める位置を組み立て直します。
